# XSLT30 temporary-element attribute mode policies -- 2026-09-02

## Result

FastXSLT executes the unchanged W3C XSLT30 `mode-0015` case. A source-free
initial-template invocation materializes one typed global temporary element
with its literal `bar="42"` attribute, then applies the native `shallow-copy`,
`shallow-skip`, and `text-only-copy` policies. The unchanged `@bar` template
rule is selected where each policy requires attribute traversal, and the
native XML assertion passes.

## Implemented semantics

- The bounded global temporary-tree constructor accepts static literal
  attributes and an exact `as="element()"` declaration for one element.
- Temporary attributes are immutable XDM nodes with expanded names, string
  values, element parents, and independent XDM-node charges. They are not
  misrepresented as child nodes.
- Temporary template selection recognizes exact and wildcard attribute
  patterns, including a rule declared in `mode="#all"`.
- `shallow-copy` applies templates to the combined attribute/child sequence,
  copies unmatched attributes onto the result element, and places nodes
  generated by matching attribute rules before generated child content.
- `shallow-skip` applies templates to attributes and children without copying
  the element. `text-only-copy` descends through children only.
- Attribute and child templates observe positions and sizes from the same
  combined sequence when the shallow-copy or shallow-skip policy selects both.

## Boundary

This does not admit dynamic attribute value templates in global temporary
constructors, standalone temporary-attribute result construction, namespace
nodes, or general typed global expressions. At this checkpoint the ordinary
source-tree shallow-copy lane still reported attribute-template interception as
unsupported; that separate result attachment path was subsequently admitted
and conserved by the
[source shallow-copy attribute override slice](xslt30-mode-source-shallow-copy-attribute-override-2026-09-02.md),
not silently inferred from temporary-tree support.
