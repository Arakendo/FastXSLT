# XSLT30 source shallow-copy attribute override -- 2026-09-02

## Result

FastXSLT executes the unchanged W3C XSLT30 `mode-1413` case over the native
`mode-14` source and matches its complete file-backed XML result. Named mode
`s` uses `on-no-match="shallow-copy"`, an explicit `@length` template replaces
each copied attribute with an incremented value, and the `chtitle` wrapper
continues through `xsl:next-match` into the built-in shallow-copy rule.

## Implemented semantics

- Source-element shallow-copy applies templates to attributes before children
  instead of copying every source attribute blindly.
- Attributes and children share the combined focus sequence, so template
  position and size remain consistent across both phases.
- A generated attribute is carried as private pending construction state and
  attached to the copied result element. Non-attribute nodes generated by an
  attribute template precede the generated child content.
- Duplicate generated expanded attribute names fail with `XTDE0410` rather
  than silently overwriting one another.
- Source comments reached by shallow-copy are now represented and serialized.
- Existing instruction, template-selection, result-node, and result-text charge
  points remain active across the added path.

The standalone instruction slice is intentionally exact: it accepts an
unprefixed static `xsl:attribute` name and the case-required integer expression
`select=". + 1"`. It does not admit general arithmetic, dynamic attribute
names, namespace expressions, or arbitrary standalone computed-attribute
content.

## Conservation

A focused private regression preserves both newly represented source paths:
comment copying and an attribute template that produces text rather than a
replacement attribute. The latter omits the intercepted source attribute and
places the generated text before ordinary child results.

The complete 169-case `attr/mode` denominator moves from 82 to 83 passes and
from 42 to 41 visible default not-run cases; its 45 profile exclusions remain
unchanged. Across the eleven conserved XSLT30 denominators, the total moves
from 402 to 403 passes and from 75 to 74 visible default not-run cases, with
three engine-unsupported cases and 51 profile exclusions unchanged.
