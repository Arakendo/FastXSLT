# Shared evidence

Evidence records reproducible observations, not public guarantees. Each record
should identify its date, inputs/revision, environment, method, results,
limitations and the decision or plan it informs.

The historical campaign migration moved 982 records into [Campaigns](../Campaigns/README.md).
This directory retains 63 shared design/foundational records; they are grouped
below by responsibility rather than assigned to an artificial blocker campaign.
New campaign-specific evidence belongs with its campaign.

See the [migration manifest](../Campaigns/evidence-migration-2026-10-22.json)
for old/new paths and preservation hashes. No observations, corpus credits or
architectural dispositions were changed by reorganizing the records.
